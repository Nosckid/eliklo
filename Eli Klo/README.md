## How to use

- **View the site:** double-click `site/eli-klo.html` — it opens in any browser, no internet or setup needed.
- **Photos are embedded** as base64 inside the HTML. Moving or renaming files in `assets/` will NOT break the site. `assets/` is the source library for future edits.
- **To swap a photo:** ask Claude to replace it, and point to the file in `assets/`.
